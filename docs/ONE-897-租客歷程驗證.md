# ONE-897 BOOKING 租客歷程

## 行為

租客通過既有 LINE 身分驗證後，獨立背景請求建立隨機參照碼；失敗不阻斷預約，也不自動重送。追蹤後台只收參照碼。管理員從歷程連結到 `/admin?journey=參照碼`，登入後可查看該次登入帳號關聯的租客與合約；不是本次選定房間，也不代表同一瀏覽器所有造訪都是同一人。

租客對應存在 booking.journey_links，180 天內可查詢，本次未新增清理排程。LINE UID 不進入網頁行為資料。追蹤錯誤只送固定分類；事件不含表單內容、錯誤原文及姓名電話。新增頁沿用管理員驗證；參照碼不提供登入權限。

## 發布／回滾與驗收

從獨立 GCP 發布分支接上本功能，保留既有環境與掛載；先候選建置檢查，再切 Caddy。若出問題回復該發布的 before.caddy，保留資料表，不刪資料。

正式租客登入及 BOOKING 查看仍需可信使用原 LINE 卡片驗收；舊歷程不回填，這次不重送卡片、不重跑提醒排程。沒有刪檔。
